오늘 뭐로 긁지 - iPhone PWA

이 폴더는 iPhone Safari에서 홈 화면에 설치할 수 있는 PWA입니다.

중요:
- iPhone의 '파일' 앱에서 index.html을 직접 열면 PWA로 설치할 수 없습니다.
- 반드시 HTTPS 웹 주소로 올린 뒤 Safari에서 접속해야 합니다.
- 최초 접속 후 홈 화면에 추가하면 이후에는 앱처럼 실행할 수 있습니다.
- Service Worker가 앱 파일을 캐시하므로 최초 설치/접속 후 오프라인 실행이 가능합니다.
- 카드 설정 및 결제 기록은 localStorage에 저장되며 서버로 전송하지 않습니다.

권장 설치 순서
1. 이 폴더 전체를 HTTPS 정적 호스팅에 업로드합니다.
2. iPhone Safari에서 index.html이 열리는 주소로 접속합니다.
3. 공유 → 홈 화면에 추가 → '웹 앱으로 열기'를 켜고 추가합니다.
4. 한 번 앱을 정상 실행한 뒤 비행기 모드에서 다시 실행해 오프라인 동작을 확인합니다.
